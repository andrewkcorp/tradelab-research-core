# Governance and maintenance

TradeLab is an independently maintained, early-stage research project. The
repository owner is the initial maintainer and release decision-maker. External
contributors are welcome; no outside contributor or user base is claimed yet.

Maintainers review code, tests and methodology, decide releases, and moderate the
project's issue/PR spaces. Access can be extended after sustained, reviewed
contributions; it is not granted in exchange for stars or promotion.

Research-model changes require an issue describing the current contract, proposed
change, bias risks and acceptance tests. Reviewers must distinguish software
correctness from evidence of statistical generalization or profitability.

AI assistants may draft and test changes. They cannot approve their own changes,
publish releases, alter repository visibility or submit funding applications.
Those decisions remain with the human maintainer.

Project communication should be respectful and evidence-led. See
[CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) for moderation expectations.
